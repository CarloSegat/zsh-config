# Docs

Applies to documentation of code in every repo: docs you write and docs a plan or task tells you to write. Not to prose that is the repo's product (papers, books, articles): there, cut words per `prose.md`, never content.

Delete as much documentation as you can. Keep a line only when a reader needs it to use or change the code and the code cannot say it.

Every doc you keep stays current: a change that makes a line wrong fixes or deletes it in the same commit. Touching a doc means also deleting what in it is stale.
